# O4.2
**Passive Voice (B1 English)**

**Formation:**
Use **be + past participle** of the main verb.

* Present: *is/are + past participle* → *The book is read by many people.*
* Past: *was/were + past participle* → *The cake was eaten yesterday.*
* Future: *will be + past participle* → *The work will be done tomorrow.*

**Usage:**

1. Focus on the **action** or **receiver**, not the doer.
2. Use when the **doer is unknown or unimportant**.

**Examples:**

* Active: *People write letters.* → Passive: *Letters are written (by people).*
* Active: *They built this bridge in 2000.* → Passive: *This bridge was built in 2000.*

This keeps sentences clear and formal.
